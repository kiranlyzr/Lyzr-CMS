# Lyzr Product Pages CMS

Private CMS to edit and publish three standalone-HTML pages on lyzr.ai (Open Finetuner, Sovereign AI, Open Cowork): sign-in, HTML checks, Desktop/Tablet/Mobile preview, publish, draft, restore.

**Documentation: [docs/](docs/README.md)** (user guide, page rules, authentication, WordPress bridge, deployment, status).

Quick start: `npm install && npm run dev` (test mode: no login, no writes) and `npm test`.
Live: https://lyzr-product-pages-cms.vercel.app
